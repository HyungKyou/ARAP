# AR/AP 환율 예측 기반 환차·환산손익 리포트 Agent

국제금융팀이 매일 SAP에서 AR(매출채권)/AP(매입채무) 원장을 수기로 내려받아 만기 구조를 분류하고,
환율 전망은 개인 리서치에 의존해 참고하던 작업을 자동화한 Streamlit 대시보드입니다.

당일 기준 AR/AP 원장과 기관별 환율 전망치를 입력받아, 만기 구조·기표환율·예측환율 시나리오별
환산·환차손익을 자동으로 계산해 보여줍니다. AI 자동수집 시나리오와는 별개로 담당자가 직접 환율을
입력해 즉시 손익을 확인할 수도 있습니다.

> 상세 요구사항은 [`PRD_AR_AP_환율예측_환산손익_리포트.md`](./PRD_AR_AP_환율예측_환산손익_리포트.md)(v1.3)를 참고하세요.

## 화면 구성 (4페이지)

1. **📊 당일 AR/AP 분석** — 만기일자별 AR/AP 그래프(AR/AP/Net 선택 표시), 상세 표, AR/AP 가중평균 기표환율, 데이터 품질 배지(격리/제외/연체/네고/매매기준율 이상)
2. **🔮 환율예측치** — 기관별 당월말·올해 분기별·내년도 전망치 표 → 백분위 시나리오(P10~P90) 순서로 표시
3. **⚖️ 환차·환산** — 원/달러 환율을 입력하면 버튼 없이 즉시 당월 말 기준 손익 미리보기 표시, 별도 버튼으로 시나리오 비교(최대 5개)에 추가, 환차손익/환산손익/합계를 탭으로 완전히 분리
4. **📐 가정사항 및 주의사항** — 계산 가정사항, 현재 버전의 한계, Excel 다운로드

사이드바(모든 페이지 공통)에서 AR/AP 원장 업로드, 보고기준일, 당일 매매기준율(+ 참고용 USD/JPY·EUR/USD 교차환율)을 설정합니다.

## 기술 스택

- **Python** + **pandas** — 원장 정규화·검증·환산·손익 계산 엔진
- **Streamlit** (`st.navigation`) — 4페이지 대시보드
- **Altair** — 만기월별 AR/AP 차트
- **openpyxl** — 원장 xlsx 파싱 및 Excel 리포트 내보내기
- **pytest** — 단위/회귀 테스트 53개

## 프로젝트 구조

```
app.py                  # Streamlit 진입점(라우터) — 사이드바 + 공통 파이프라인 실행
app_pages/               # 4개 페이지 (계산 로직 없음, src/ 결과를 표시만 함)
  page1_ar_ap.py          # 당일 AR/AP 분석
  page2_forecast.py       # 환율예측치
  page3_pnl.py            # 환차·환산
  page4_notes.py          # 가정사항 및 주의사항
src/
  ingest.py               # AR/AP 원장 로더 (SAP 추출 컬럼 → 표준 스키마)
  validate.py             # 검증/정제 7규칙 (격리·제외·플래그)
  fx_engine.py            # USD 환산, 가중평균 기표환율
  pnl_engine.py           # 시나리오별 환차·환산손익 계산
  forecast_source.py      # 예측환율 수집(현재 mock) + 백분위 시나리오 산출
  manual_input.py         # 수동 환율 입력 이력 관리
  maturity_view.py        # 만기월 버킷팅
  charts.py               # F1 차트
  formatting.py           # 숫자/부호 표시 규칙
  report_export.py        # Excel 리포트 내보내기
tests/                   # pytest 53개
scripts/verify.py        # UI 없이 계산 파이프라인만 검증하는 CLI 스크립트
실습AR_300건.xlsx / 실습AP_300건_v2.xlsx   # 샘플 원장 (실제 SAP 추출 컬럼 구조 반영)
```

## 시작하기

```bash
pip install -r requirements.txt
streamlit run app.py
```

브라우저가 열리지 않으면 `http://localhost:8501` 로 접속하세요. 파일을 업로드하지 않으면 번들된
샘플 원장(`실습AR_300건.xlsx`, `실습AP_300건_v2.xlsx`)으로 바로 동작합니다.

다른 AR/AP 파일도 업로드할 수 있지만, 번들 샘플과 **컬럼 구성이 동일한 SAP 추출 형식**이어야 합니다.
컬럼명이 다르면 어떤 컬럼이 필요한지 화면에 안내됩니다.

## 테스트

```bash
python -m pytest tests/ -q                # 전체 테스트
python scripts/verify.py                  # UI 없이 계산 결과만 빠르게 확인
```

## 현재 버전(v1)의 한계

- 2번 페이지의 기관별 전망치는 실제 리서치 자료 실시간 수집이 아니라 예시(mock) 데이터입니다 (`ForecastSource` 인터페이스만 교체하면 실 수집기로 전환 가능).
- PDF 다운로드는 아직 지원하지 않습니다 (Excel만 가능).
- 사내 접근 권한 통제(로그인 등)가 없습니다. 거래처명 등 민감정보가 그대로 노출되므로 사내 배포 전 별도 접근 통제가 필요합니다.
- 평일 오전 자동 실행 등 예약 실행 기능은 없습니다.
- 업로드 파일의 컬럼명이 SAP 표준과 완전히 일치해야 합니다 (유사 컬럼명 자동 매핑은 로드맵).
